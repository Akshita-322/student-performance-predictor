# Student Performance Prediction System

A beginner Machine Learning project that predicts student marks based on:
- Study hours
- Attendance
- Sleep hours
- Assignments completed

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithm
- Linear Regression

## Features
- Predicts student marks
- Uses ML model training
- Data visualization included

## How to Run

1. Install libraries:
pip install -r requirements.txt

2. Run project:
python main.py
